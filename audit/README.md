# Valve Oil Q2 port audit

Local audit branch based on Valve Oil dev `5dbd27ee3c807013f68ef57e1b2b15044f5b61aa` (package 26.11.10.3). Branch `q2-release-baseline` retains the reviewed main snapshot `96892f2d6aa0e6238f02e151beb7bd5e3202d02e`. Q2 remains outside the supported-printer manifest.

The audit marker makes the local installer bootstrap and CLI, release download wrapper, bundle builder and three standalone firmware flash CLIs exit before doing their work. This is an accidental-execution guard for this checkout. The audit script reads local snapshots and writes Markdown to stdout. It uses no printer connection and starts no services. The branch contains no captured printer configs or raw logs.

## Evidence

- Max 4 stock values come from the four bundled restore trees (01.01.06.03, .06.04, .06.05 and .07.01). The upstream provenance ledger records release/archive hashes for .06.05 and .07.01. Source-replacement hashes in the comparison are manifest expectations. Missing stock source stays unverified. [Max 4 snapshot provenance](../installer/stock/qidi-max4-defaults/README.md)
- Q2 stock values come from the saved October 26 factory-restore capture for 01.01.03.02, before restoring our custom integration. Calibration values are machine observations. QIDI's download page still listed that firmware at audit time. The public QIDI_Q2 main checkout at `3f6bcc8bc295ecf067b45345c5bdb2139b287f17` dates to January 5, so its configuration is a historical reference. [QIDI firmware page](https://www.qidimaker.com/en/downloads/firmware/Q2) · [Public Q2 source](https://github.com/QIDITECH/QIDI_Q2/tree/3f6bcc8bc295ecf067b45345c5bdb2139b287f17)
- The [generated comparison](manifest-comparison.md) lists every manifest option change, section removal, guarded source replacement and implementation file by category. Reproduce it with `python3 -B audit/compare_stock.py /path/to/captured/service-home`. An absent section at the Max 4 path can be present in another Q2 file. Textual matches establish a starting value only.

## Feature comparison

| Area | Stock Max 4 → Valve Oil | Stock Q2 and port decision |
|---|---|---|
| Homing and motion | Faster X/Y first and second homes, different retract distance and speed, shorter Z retract, Max 4-specific homing source replacement, fewer redundant homes. Max velocity changes 800 → 565 mm/s. | Q2 stock limit is 600 mm/s and 20,000 mm/s² vs Max 4's 800 and 30,000. X/Y both start at 50 but retract distance is 0 on Q2 vs 50 mm on Max 4. Q2 has no explicit second-home or retract-speed options at the targeted sections. Stock Q2 .03.02 wraps G28 for lazy homing and has its homing override in `gcode_macro.cfg`. Preserve its sequence pending a Q2-specific motion review. |
| Leveling and print start | Faster mesh and Z-tilt travel, bounded probe retries, background mesh save, adaptive or saved mesh, nozzle wipe/scrape and front prime, guarded Z-offset persistence. Orca and Studio slicer packs call the optimized path. | Q2 mesh travel is 100 vs 150 mm/s on Max 4. Z-tilt starts at 150 on both, with different geometry. Evaluate retry, save and offset logic separately. Use Q2's cutter, wipe, probe and prime geometry when designing slicer macros. |
| End, pause and temperature | Keep filament loaded, same-slot reheat avoidance, long-pause cancellation, staggered heating, Orca minimum chamber threshold, coordinated chamber/exhaust logic, fan and temperature-wait wrappers. | The Q2 stock macro layout differs. Q2's captured chamber protection sensor is 150 °C. The Max 4 manifest's applicable newer stock uses 170 °C. That is a safety threshold, so preserve Q2's value. Check heater/fan names and slicer placeholders before evaluating behavior. |
| Box movement and recovery | Per-slot feed speeds, jog, cold cut/unload/eject, less eject homing, guards for stale loaded-slot state, flow stop/retry, stranded filament, runout and resume fixes. | Q2 .03.02 already addresses unwanted homing during Load after runout. Compare the actual Box flow and controller events before adopting motion changes. Our stale identity after spool replacement is a separate lifecycle question. |
| Box link and shutdown | Preserves original errors, monitors Box links and MCU temperature, refreshes Box heaters more often, reduces redundant RS485 probes, protects USB serial ownership, and changes USB Box firmware shutdown behavior. | The Q2 capture includes a configured RS485 section. Our later USB-only trial disabled it when the optional adapter was absent. Start with diagnostics and exact transport/command checks. Verify heater and shutdown behavior on each board before any changes. |
| RFID and filament catalogs | Stock QIDI tag workflow gains factory Anycubic, Elegoo and Bambu support via custom USB Box firmware and Klipper, plus vendor catalog additions and tag reports. Tag writing is tracked separately as proposed work. | Stock Q2 supports QIDI's tag workflow. Our installed Q2 uses a TinkerBarn tuple adapter and read guard. Factory-tag integration requires exact Box board, bootloader, protocol and recovery checks. Preserve assigned IDs and Studio presets. The prior comparison found 62 conflicts with our deployed Q2 0.4 catalog. |
| Fluidd and native catalog | Serves an updated Fluidd fork alongside the stock copy, adds a Box path card, slot controls, catalog editor/import/export, touchscreen viewer and service restart. Includes an older bundled-asset patch path. | Our Q2 already uses the older compatibility approach. Check the new fork against saved Q2 status objects, partial updates and command contracts. Treat the catalog editor's ID allocation and writes as a separate integration with our registry. |
| Moonraker and file metadata | 3MF plate handling, used-filament metadata, faster startup, serialization/event-loop improvements, per-slot Spoolman and purge accounting. | Compare exact Moonraker sources and captured metadata before adopting patches. Q2 reported Python 3.9 and aarch64, which is only a first check for binary dependencies. Test Studio and Orca files separately. Spoolman needs its own configured service and slot tests. |
| Klipper loop and upstream backports | Cleans up load timers, reduces repeated status and saves, yields during G-code streaming, improves MCU failure diagnostics, applies version-guarded homing, probe and scheduling fixes. | Start with read-only timer/link measurements. Match source guards per firmware and exercise changed timer, homing and shutdown contracts offline. The stock config capture alone cannot verify these runtime defects. |
| Calibration and motor diagnostics | Load-cell check, probe accuracy and screw tools, newer resonance sweep, default input shaper, optional closed-loop slip detection/recovery, bed soak diagnostic. | Use Q2-specific coordinates, sensor assumptions and calibration. Q2's active X/Y sections in the capture use TMC2240, with closed-loop sections commented. The Max 4 slip monitor and reply patch have no demonstrated Q2 equivalent. |
| Board firmware | Separate USB Box, toolhead LIS2DW FIFO and Max 4 mainboard reply fixes with hardware identity checks and restore paths. | All require independent Q2 board and bootloader qualification. Config or protocol resemblance is insufficient. |
| OS, services and recovery | CPU frequency and priorities, IRQ pinning, zram, DNS/APT changes, storage mount repair, reduced screen animation, optional AI disable, disables network ADB, camera readiness and service restarts. Installer includes backups, staged changes, reboot and automatic updates. | Captured Q2 reports Debian 11 and kernel release 5.10.160. Exact kernel build and module ABI still require evidence, as do IRQ layout, service dependencies and storage behavior. Evaluate each change independently. Stock recovery and calibration preservation need a Q2-specific rehearsal. |
| New dev UI and add-ons | Dev adds an optional Valve Oil UI alongside Fluidd and an add-on manager starting with OctoEverywhere. Both extend installation and service scope. | Evaluate separately. The UI issues real Moonraker controls and depends on the same Box contract. Add-on service and account linking are outside the printer compatibility test. |
